# Brain-CT-UNET-Segmentation-Model
UNET based segmentation model trained using both non-penetrating and penetrating traumatic brain injury head CT scans. Model uses a cross validation ensemble approach with 2.5D inputs.

# Abstract:
Purpose: Brain tissue extraction from medical images is a frequently implemented preprocessing step that removes unwanted information. This study explores the use of convolutional neural networks (CNNs) for automated brain extraction and transfer across disease conditions on CT scans acquired from patients with either non-penetrating or penetrating traumatic brain injury (TBI).
Approach: The dataset consisted of a total of 50 cases, cohorts of 30 non-penetrating TBI (np-TBI) and 20 penetrating TBI (p-TBI) cases. Out of the total dataset, 6 cases from each subset were held-out into an independent testing set. Model A used 8-fold cross validation. CNNs were initially trained on the remaining 24 np-TBI cases to extract the brain. To improve model performance, a second model was developed by fine-tuning Model A using the p-TBI dataset. Further, a third model (Model C) was trained using both np-TBI and p-TBI datasets. All model performance was evaluated on the held-out independent testing set. Dice-Sørensen Coefficient (DSC) and Hausdorff Distance (HD) were used as metrics of performance.
Results: Model A tested on the independent np-TBI cohort yielded a DSC = 0.956 [0.938, 0.969] (mean [95% CI]) and HD = 9.76 [8.37, 11.2] mm and on the independent p-TBI test set yielded a DSC = 0.930 [0.906, 0.949] and HD = 16.7 [14.3, 19.1] mm. Model B resulted in a DSC = 0.943 [0.926, 0.956] and HD = 16.3 [14.0, 18.7] mm when tested on the independent p-TBI test set. Model C yielded a DSC of 0.968 [0.958, 0.976] and HD =8.86 [7.74, 9.99] mm and DSC = 0.952 [0.933, 0.967] and HD =12.3 [10.6, 14.1] on the independent np-TBI and p-TBI sets, respectively. In general, np-TBI segmentation performance was higher than p-TBI segmentation performance, though this difference failed to demonstrate statistical significance. Models fine-tuned with p-TBI data did not demonstrate improvement. Combined np-TBI and p-TBI data yielded an improvement as indicated by Model C HD performance. 
Conclusion: On a clinical dataset, this study shows the promise of automated segmentation for brain extraction on CT images that could be efficiently implemented in larger machine learning workflows, alleviating the burden of manual segmentations.
